## 配置说明（config.py）

```python
# 1) 路径统一基于项目根目录计算，不依赖运行目录
BASE_DIR = Path(__file__).parent

# 2) BERT 预训练模型：指向共享目录，不复制进项目
#    默认复用 第4周/models/google-bert/bert-base-chinese（已下载 1.6G）
#    如需完全自包含，可改为 assets/models/bert-base-chinese 并自行放置模型
BERT_MODEL_PERTRAINED_PATH = BASE_DIR / '../../models/google-bert/bert-base-chinese'

# 3) API Key 走环境变量，不硬编码
LLM_OPENAI_API_KEY = os.environ.get("DASHSCOPE_API_KEY", "")
```

## 关键设计决策（相对原项目的改进）

| 决策 | 原项目 | 重实现 |
|---|---|---|
| 预训练模型存放 | 项目内 assets/models（未下载） | **指向共享目录** `../../models/google-bert/bert-base-chinese`，不复制 1.6G |
| 标签映射持久化 | 无（推理端硬编码类别数组） | **labels.json** 随 bert.pt 一起产出，推理端动态反查 |
| 类别数量 | 硬编码 12 | 训练脚本从数据自动推导，写入 labels.json |
| API Key | 明文硬编码 | **环境变量** DASHSCOPE_API_KEY |
| 停用词加载 | 在线 URL（断网即崩） | **本地文件** assets/dataset/baidu_stopwords.txt |
| BERT 模型加载 | import 时立即加载（启动慢、权重缺失即崩） | **懒加载单例**，首次调用才加载 |
| 路径 | 相对运行目录（换目录即挂） | 基于项目根目录 `BASE_DIR` 计算 |
| 正则列表分支 | 变量 bug（findall 整表） | 修复 |
| transformers 5.x 兼容 | 用的旧版参数（logging_dir 等） | 新写法（eval_strategy、warmup_steps） |

## 使用流程

```bash
# 1. 静态资产（一次性）
#    从 01-intent-classify/assets/dataset/ 复制 dataset.csv、baidu_stopwords.txt

# 2. 训练 TF-IDF 模型（约 1 分钟，CPU 即可）
conda activate py312
python train/train_tfidf.py

# 3. 微调 BERT（约 5 分钟，GPU）
python train/train_bert.py

# 4. 设置大模型 API Key（仅 GPT 接口需要；无 key 时其他 3 个接口不受影响）
export DASHSCOPE_API_KEY=sk-xxxx          # Windows: set DASHSCOPE_API_KEY=sk-xxxx

# 5. 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000

# 6. 冒烟测试（另开终端）
python scripts/test_api.py
```
