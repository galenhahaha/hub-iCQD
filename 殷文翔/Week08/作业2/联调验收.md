## 接口、持久化与前端

- `GET /health` 返回 200，`POST /api/research` 返回 202 + UUID；前端自动轮询至 completed。
- 轮询的最终响应与磁盘 JSON 完全一致，并符合 `ResearchRecord` 结构。
- 桌面端四个标签页的来源数量、过程步骤、摘要与置信度日期均与返回数据一致。
- 生成的 HTML 在禁用脚本的 sandbox iframe 内预览；Markdown 报告可正常下载。
- 刷新页面可从 URL 恢复任务；390px 手机视图无横向溢出，历史菜单可打开并切换研究。
- 真实验收期间无浏览器 JavaScript 异常。

离线回归：50 项后端测试、10 项 Agent 自测全部通过。额外浏览器回归核对空白主题校验、阶段性草稿、失败后保留进度、过期响应隔离、断线重试、非可信文字与链接展示、HTML 脚本隔离、键盘标签切换和 360px 布局，不调用外部 API。
